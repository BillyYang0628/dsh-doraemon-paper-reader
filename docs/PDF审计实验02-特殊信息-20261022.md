## 4. 真实根因与迭代

### 4.1 无 `BEGIN/END` 的算法

旧算法收集器只接受 `Algorithm -> BEGIN -> steps -> END`。新论文使用：

```text
Algorithm 1. QFP
Input: ...
While ...
  If ...
  ...
Endwhile
```

改为双模式：

- 有 `BEGIN/END`：保持旧模式；
- 无显式边界：从算法题注开始，按同栏、字号、算法语法和正文尺寸停止。

控制流从整数计数改为结构栈：

- `While / For / Foreach / If / Function` 入栈；
- `Endwhile / Endif / Endfunction` 回退到对应结构；
- 省略中间 `End If` 时，外层 `Endwhile` 可关闭未闭合分支；
- `Else / Else If` 对齐最近的 `If`。

最终 IoT 保留 Algorithm 1/2/3，共 6/19/12 个步骤。

### 4.2 无边框表

综述的表多数没有 PDF 边框。新增无框表区域：

- 先按题注所属栏过滤；
- 全宽题注按其中心判断；
- 吸收密度更高的小字号表格行；
- 遇到正文尺寸、下一个题注或 heading 停止；
- 长表继续沿同栏扫描，不被另一栏同高度的标题截断；
- `tableText` 保留每一源行的换行。

最终 14/14 张表全部进入 MirrorDoc。

### 4.3 表题只有 `TABLE N`

部分表题没有句点和标题，只有 `TABLE 7`，下一行才是全大写副标题。现在：

- 独立的 `TABLE N` 识别为 caption；
- 同栏、全大写、紧邻副标题进入题注；
- 不再因为字号重复签名被 running-head 规则误删。

Table 2 最终题注为 `TABLE 2 SUMMARY OF THE RELATED WORKS`，不再混入正文碎片 `tection`。

### 4.4 跨栏合并行

full-width 文本分组会把同高度的左右栏内容拼成一行。新增两类切割：

- 左侧以编号 heading 开头、右侧是另一栏正文；
- 左侧是正文、右侧以编号 heading 开头。

修复后：

- `4.3 Tweet Analysis Approaches` 与右栏正文分离；
- 4.4 `Network Analysis Approaches` 从正文尾部恢复为 heading；
- `8. Additionally, Table 1 depicts...` 保持正文，不再进入目录。

### 4.5 图内文字与矢量图

- 图片 crop bbox 内的文字归入 figure source，不再作为短正文清理；
- 当 PDF 只有矢量曲线/线段、没有 image XObject 时，聚类真实矢量对象形成 figure；
- 曾尝试“白空格直接当图”的 fallback，但旧 Sensors 样本立刻少 heading/公式、AIoT 多出伪图，因此该方案被回归否决，没有保留。

### 4.6 参考文献与作者简历

作者简历的年份行如 `2015. His research interests...` 被旧规则当成参考文献编号。现在：

- 纯数字编号只接受 `<=999`；
- 检测到作者简历起点后，后续行归为 meta，不进入 reference；
- IoT 恢复为 1–20，Twitter Review 恢复为 1–91。

### 4.7 Abstract / Index Terms

IEEE 模板使用：

```text
Abstract—正文
Index Terms— ...
```

现在冒号、长破折号、短破折号均可作为结构分隔符；两篇论文都恢复 abstract、keywords、authors。

## 6. 回归策略

本轮共做了 4 次阶段回归：

1. 第一批无框表/算法改动后，旧四篇 4/4 通过；
2. 匹配 Abstract、算法栈、跨栏标题后，旧四篇再次 4/4；
3. 白空格 vector fallback 导致 Sensors 少 heading/公式、AIoT 多伪图，方案被撤销；
4. 改用真实矢量对象聚类后，旧四篇恢复全绿，再跑包含两篇新论文的 6 篇回归，全部通过。

新回归样本是 optional local cases：

- `iot-special`
- `twitter-review-special`

样本存在时自动运行；clean checkout 没有 ignored PDF 时标记 optional skip，不把“未运行”伪装成通过。
