## 1. 结论

1. 当前首批生成图**不合格，不进入插件**。它是通用平滑动漫少女，不是定稿主形象。
2. 问题不是“某一张随机画错”，而是旧提示词把鲸鳍描述成模糊的
   `fin-like ears`，没有明确禁止兜帽顶耳朵、红球呆毛、开襟披风和单层下摆；
   同时允许 `soft anime illustration`，与定稿的 16-bit 像素风直接冲突。
3. 后续先生成通过身份验收的**静态关键姿态**，再做少量动作帧。循环动效禁止逐帧独立文生图，
   否则帧间发色、兜帽、披风、尾巴和像素格都会漂移。
4. 插件运行时继续使用透明 PNG/WebP + PNG 精灵图 + CSS `steps()`。
   当前资源路由不接受 `.gif`；在资源白名单和 L0 安全测试没有单独升级前，不把 GIF 塞进 `assets/`。
5. 吉祥物只进入空态、加载、成功、局部失败和首次引导。
   论文正文、图表/公式内部、引用卡、查词卡、批注浮层和双篇正文栏不出现吉祥物。

### 3.1 人物—物品物理关系

任何手持、抱持、叠放或落地道具都必须通过以下规则：

1. **有接触**：至少有一个清晰可见的接触点，手、前臂或身体必须真正碰到道具；不能悬浮。
2. **有支撑**：抱书时双手/前臂托住重量；举书时必须从下方或侧面托住；叠书必须有下层书本承重。
3. **有遮挡**：明确手掌、手指、袖子、道具和身体的前后顺序，禁止图层互穿。
4. **有重心**：道具重心位于支撑范围内；不能用一只悬空手指挑起厚书或放大镜。
5. **有落点**：掉落道具的底边接触地面，脚、尾巴和道具之间保持合理间距。
6. **有比例**：同一道具跨状态保持接近的大小、透视和材质；不能一本书大、一本书小。
7. **无魔法悬浮**：除非状态文案明确是魔法效果，否则物体不得自行漂浮、吸附或穿插。

## 6. 动效规格

| 项目 | 规则 |
|---|---|
| 格式 | 透明 PNG 精灵图横排；插件通过 `background-position` + CSS `steps()` 播放 |
| GIF | 当前不进入运行时；资源路由白名单没有 `.gif` |
| 帧率 | 8～10 fps，保持像素动画的节奏 |
| 循环 | `loading-wait`、`thinking` 循环；`success` 只播放一次并停在最后一帧 |
| 动效范围 | 每帧只允许 1～2 个局部动作；头身比、镜头、兜帽、披风和色板保持不动 |
| 真机尺寸 | 大状态 120～160px；行内状态 24～40px；一律整数倍缩放并启用 `image-rendering: pixelated` |
| 文件预算 | 单个静态透明图 ≤160 KB；一套精灵图 ≤500 KB |
| 降级 | `prefers-reduced-motion` 显示通过验收的首帧或完成帧；不播放循环 |
| 无障碍 | 装饰图 `aria-hidden`；带含义的图使用对应 `alt`，状态本身仍由文字或 `role=status/alert` 表达 |

帧间一致性流程：

1. 先生成一个静态关键姿态并验收 C01～C14；
2. 从关键姿态派生帧，不重新跑整段提示词；
3. 每帧只修改计划中的局部层，例如纸边、眨眼、三点、星星；
4. 叠帧检查兜帽轮廓、发际线、披风外轮廓、尾巴根部、脚底基线；
5. 任何一帧身份漂移，整组重做，不把问题帧硬接进循环。
