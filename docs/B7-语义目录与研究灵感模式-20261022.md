# B7：语义目录与研究/灵感模式

## 1. 完成范围

闭合 R-006 与 R-019：

- 由插件通读论文结构，生成两层语义目录；
- 原始标题、blockId、页码和顺序由 MirrorDoc 决定，模型只能生成中文标签与概括；
- 中文、原文、对照三种阅读模式下同步展示目录；
- 模型失败时回退原文 heading，并明确标记；
- 目录滚动时更新当前章节；
- 左侧目录下增加默认精读 / 研究模式 / 灵感模式；
- 研究方向只保存在本地；
- 研究模式只在回答末尾增加方向关联；
- 灵感模式提供可验证创意，并通过 B5 检索能力做谨慎查新。

## 2. 语义目录

新增：

```text
src/outline.js
```

职责：

- 从 MirrorDoc 构造压缩但覆盖全文 heading 的目录输入；
- 排除 References、致谢、Supporting、算法/表格/图注污染；
- 生成模型 JSON 提示词；
- 校验 blockId、顺序、重复项和特殊块污染；
- 模型失败时构造确定性回退目录；
- 根据语言模式生成显示字段。

目录数据保存在作业目录：

```text
semantic-outline.v1.json
```

缓存键是目录输入 hash；heading、章节 gist 或摘要变化后自动失效。

## 3. 语义目录校验

模型不能直接决定导航结构，必须满足：

- `blockId` 必须真实存在；
- 每个 heading 最多出现一次；
- 缺失 heading 会补入“其他章节”，不能静默丢失；
- References、算法、表格、图注不得进入；
- 原始标题与页码从 MirrorDoc 回填；
- 失败时保留原文目录并显示原因。

## 4. 目录 UI

- 桌面左栏扩为 `220–286px`，正文列保持自适应；
- 目录字号提升到 12px，支持两行；
- 一级语义组显示中文组名与短概括；
- 原文模式：中文语义组 + 英文原 heading；
- 中文模式：中文语义组 + 中文 heading；
- 对照模式：中文 heading 为主，英文原 heading 为副标题；
- 滚动正文时使用 `requestAnimationFrame` 更新唯一 active 项；
- 目录自身滚动，模式按钮固定在目录底部；
- 375px 改为横向目录，三个模式按钮仍可见。

## 5. 研究/灵感模式

阅读页目录下提供三态单选项：

```text
默认精读 | 研究模式 | 灵感模式
```

模式按 jobId 保存在本地；研究方向使用独立本地 key：

```text
doraemonPaperReader.readerMode.<jobId>
doraemonPaperReader.researchDirection
```

研究方向不会写入仓库、公开日志或其他用户数据。

### 研究模式

- 未填写方向时不启用，直接打开编辑框；
- 主体回答继续遵守 B6；
- 只在末尾增加“与你的研究方向”；
- 区分“论文明确支持”“模型推导”“相关但未验证”；
- 关联弱时允许直接说明。

### 灵感模式

- 先解释原文，再给 1–3 个创意；
- 每个创意要求原文锚点、数据/实验需求、风险和反例；
- `doraemon_search_novelty` 工具使用 B5 多路召回查询真实题录；
- 结论只使用“高度相似 / 部分相关 / 当前检索未发现”；
- 无检索或无充分证据时明确“未查新”，不得声称绝对新颖。

## 10. 边界

- 语义目录的标签质量仍需人工复核；
- 目录模型不可用时只提供原文 heading 回退；
- 研究方向按当前设计保存在浏览器本地，不跨设备同步；
- 查新依赖 OpenAlex/Crossref/DataCite/arXiv，当前检索未发现不能证明绝对新颖；
- B7 不改变 PDF 块顺序、引用锚点、翻译证据、批注存档或版本信息。

## 11. 2026-10-22 实测修复

- `Not found` / HTTP 404 不再直接进入用户提示；

- 服务端同时把 Not found、超时和缺少模型凭据映射为中文回退原因。

### 研究模式首次启用说明

- 仍先解释论文本身；
- 只在回答末尾分析方法、数据、实验或工具与研究方向的关系；
- 研究方向只保存在本机；
- 未填写方向不会启用。
