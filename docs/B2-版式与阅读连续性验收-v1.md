# B2 版式与阅读连续性验收 v1

> 对应 [`问题处理方案-v1.md`](问题处理方案-v1.md) 的 B2：R-001、R-003、R-010、R-014、R-015。

## 1. R-001 深色主界面插画背景与署名

改动：

- 深色主题 `.dpr-mascotSticker` 从暖色/灰黑混合改为品牌蓝 + 深色表面。
- 边框和硬边阴影跟随品牌蓝，不再形成脏灰方底。
- 中文署名改为“**在下大肥鱼，请指教**”。
- 英文标识同步为 `At your service - Big Fatty Fish`。

验证：

- 主界面亮/暗 L2 通过。
- 视觉证据 `工具/gen/B2-20261021/main/main-interface-dark.png`。

## 2. R-003 抄写页插画重排

改动：

- 插画从 `92px` 放大到 `216px`，为原来的约 **2.35 倍**。
- 加载 Hero 从左右双栏改为纵向：插画在上，阶段文案在下。
- 移除 `.dpr-mascotSlot` 背景、边框、点阵和 `::before` 虚线。
- 删除“大肥鱼正在一页页翻书”的 DOM 节点。
- 成功/加载动画、减少动态、失败静态图保持原状态机。

真实盒模型：

- 成功精灵：显示 `1080×216`。
- 加载精灵：显示 `1296×216`。
- 插画与文案垂直间距不少于 8px。
- `PDF completion 375px reduced-motion` 无横向溢出。

证据：

- `工具/gen/B2-20261021/illustrations2/pdf-loading-frame.png`
- `工具/gen/B2-20261021/illustrations2/pdf-done-375-reduced.png`

## 3. R-010 阅读页宽度

改动：

- `.dpr-readerBody` 移除 840px 宽度上限，改为 `width:100%;max-width:none`。
- `.dpr-readerLayout` 上限从 980px 提升到 1470px。
- 目录列改为 `clamp(176px,16vw,244px)`。
- 正文卡宽度 100%，最大 1180px，避免无限长行。

1920×1080 实测：

- 可见插件 pane：863px。
- reader body：827px；差值 36px 为左右内边距。
- reader layout：763px。
- 不再出现由 max-width 造成的中间大块空白。

说明：DSH 主对话与右侧插件的实际分栏比例由宿主控制。本插件会填满宿主分配的 pane；如果宿主切换到约 4:6，本布局会随 pane 扩展。

## 4. R-014 目录 sticky 遮挡

改动：

- 阅读页测量 `.dpr-readerBar` 实际下沿。
- 将相对 root 的偏移写入 `--dpr-outline-top`。
- `.dpr-readerOutline` 使用动态 `top`，ResizeObserver 监听工具栏变化。

1920×1080 实测：

- 滚动后阅读栏 `bottom=119px`。
- 目录 `top=127px`。
- 目录保持在阅读栏下方 8px，无遮挡。

## 5. R-015 阅读位置恢复

改动：

- scrollTop 同时写入内存 Map 和 localStorage。
- cleanup 使用最后一次滚动快照，不读取已经脱离 DOM 的 0。
- 重开时连续多帧恢复，抵消标题、图片和字体加载带来的高度变化。
- 明确 blockId 定位仍优先于历史位置。

实测：

- 离开前 `scrollTop=1400`。
- 重新打开后 `scrollTop=1462`。
- 偏差 62px，处于同一阅读段；不再回到顶部 0。
