## 3. Before

目录：

```text
工具/gen/B4-20261022/before/tabular-embeddings-survey/
```

结果：

- `table = 0`；
- Table 1、Table 2 全被当作 paragraph；
- 12 个 `reading-order.cross-column-line` 误报，实际是单栏表格行；
- Table 1、Table 2 均为 `table.caption-unattached`。

根因：

1. 两表题注位于表格下方，旧逻辑只向下找表体；
2. 无边框表的行使用正文字号，旧逻辑把第一行正文当成表格结束；
3. 单栏表格的列间大空隙被误认成双栏混排。

## 4. 算法调整

### 4.1 单栏表格不参与跨栏告警

`reading-order.cross-column-line` 只对存在实际 `columnSplit` 的页面生效。
单栏页面的宽表格行不再被误判。

### 4.2 题注下方/上方双向找表

- 题注在表上方：按题注后的连续表格行找；
- 题注在表下方：从题注向上找；
- 多题注连续页面在下一 caption 处停止，不跨入下一张表；
- 表格行允许为正文字号，但必须存在列间大空隙。

### 4.3 行列表格结构

新增 `tableStructure`：

- `rowCount` / `columnCount`；
- `rows[].cells`；
- `rowSpan` / `colSpan`；
- `mergedCells`；
- `coveredByRow`；
- `sourceBbox`（只作诊断，不无条件扩张裁剪）。

结构识别优先使用 pdfplumber 的真实线框网格；无框表使用 header word-start + 行聚类。

### 4.4 旋转表和续表

- 页面 `/Rotate=90/270` 的横表页进入 rotated-table 流程；
- 相邻且同表头的旋转页形成 continuation group；
- 普通表格若下一页存在高密度多列表体，则生成续表 block；
- 续表继承父表 label，并记录 `continuationOfPage` / `continuationGroup`。

### 4.5 审计规则

新增：

- `table.structure-missing`；
- `table.row-width-mismatch`；
- `table.continuation-without-parent`；
- `table.continuation-unlinked`；
- `table.caption-unattached` 由 warning 提升为 error。

同时修正 `table.crop-cuts-data-rows` 的误报：至少连续 4 条可疑行才阻断。
