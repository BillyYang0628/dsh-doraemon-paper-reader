# 插画生成流程与页面落位 v1

> 本文把当前主形象、生成链路、物理约束和页面落位合成一张执行表。
> 视觉身份以 [`角色插画标准-v1.md`](角色插画标准-v1.md) 为准，页面功能以 `src/client.js` 为准。
> 本文不改变任何功能、数据或状态机。

## 1. 当前定案

| 项 | 当前结论 |
|---|---|
| 正式生图模型 | DashScope `wan2.7-image-pro` |
| 角色身份参考 | `UI/mascot-v1.png` |
| 基础六状态 | `_dpr-image-studio/output/wan27-image-pro-character-suite-v1/` |
| 动作第一版 | `_dpr-image-studio/output/wan27-action-first-v1/` |
| 已退役模型 | `qwen-image-2.0-pro`、`wan2.7-image` |
| 动画交付 | WebP/PNG 精灵图 + CSS；当前不直接交付 `.gif` |
| 背景策略 | 一套透明母版；浅色/深色由宿主卡面提供底色 |
| 插画原则 | 一屏最多一个主插画；正文、查词、引用、批注区域不放吉祥物 |

生成流程：

```text
UI/mascot-v1.png
  + character-lock-v1.json
  + 单状态姿态/道具关键词
  → wan2.7-image-pro（带角色参考）
  → 1024px 状态原图
  → C01–C14 身份与物理关系审核
  → 透明背景提取
  → 512px 运行时 WebP
  → loading/thinking/success 精灵图
  → 页面最小范围接入
  → 亮/暗、窄屏、减少动态、真实 DSH L2
```

### 2.2 当前选定套图的真实表现

`wan2.7-image-pro` 套图是目前身份和物理关系最均衡的一版，但仍需在正式接入前修正：

- 白色猫脸面板在不同状态中有轻微位置变化；
- 披风开合和双层下摆细节并非每张完全一致；
- 书本保持明显页芯、硬壳、金护角、锁扣与书签；
- `loading-wait` 使用打开的书，`stack` 使用三本叠书；
- `error-cry` 为坐地低落、书本落地；不再使用旧版的站立假哭。

### 2.3 人物—物品物理规则

1. 手、前臂或身体与道具必须有可见接触点。
2. 抱书必须托底或夹持；举书必须从下方/侧面支撑。
3. 叠书必须由下层书本承重，不能互相穿模。
4. 放大镜手柄必须穿过掌心，不能悬在手指旁。
5. 书本落地时底边接触地面，脚与尾巴不能穿过书本。
6. 每个状态都检查“袖子 → 手 → 道具封面 → 页芯/书脊”的前后顺序。
7. 禁止魔法悬浮，除非文案本身明确是魔法效果。

## 4. 动效与静态资产清单

### 4.1 循环/一次性动效

| 资产 | 帧数 | 播放 | 页面 | 位置 |
|---|---:|---|---|---|
| `loading-turn-page` | 6 帧：原页、20°、35°、50°、70°、90° | 980ms 循环，含不均匀相位 | PDF 导入加载、查询进行中 | 左侧主插画槽 |
| `thinking` | 4 | 8fps 循环 | 后续可复用查询/对照 | 32px 行内状态位 |
| `success-yay` | 5 个关键相位 | 1180ms 播放一次并停末帧；减少动态直接显示末帧 | PDF 导入完成、查询成功 | 左侧主插画槽 |

### 4.2 静态插画

| 资产 | 页面 |
|---|---|
| `home-open-book` | 主界面、PDF 未选文件 |
| `lookup-detective` | 信息查询初始 Hero |
| `error-cry` / `error-play-dead` | PDF 失败、查询无匹配/失败、阅读页整页失败 |
| `search-empty` | 如需要可复用 `error-play-dead`，不再单独生成 |
| `offline` | 网络/API 不可达 |
| `stack-books` | 综述页论文库为空 |
| `read-lying` | 阅读页无 job / 长期无法打开 |

### 4.3 独立小物件第一批

| 物件 | 页面位置 / 用途 |
|---|---|
| `hourglass` | PDF、索引和镜像处理阶段的小型等待标识 |
| `magnifier-empty` | 信息查询无结果 |
| `magnifier-found` | 信息查询命中、候选确认 |
| `highlighter` | 批注入口、首次批注引导 |
| `annotation-bubble` | 批注条与段尾批注提示 |
| `citation-chain` | 引用蓝链与引用卡片标题 |
| `version-layers` | 版本核验、版本差异入口 |
| `table-grid` | 对照表与表格产物 |
| `chart-bars` | 有出处数据图 |
| `formula-symbol` | 公式识别与修正 |
| `dictionary` | 论文术语查词入口 |
| `offline-plug` | 网络、服务不可达 |
| `toolbox` | 环境与存储、Python 修复 |
| `book-stack-small` | 论文库、最近论文 |
| `success-seal` | 导入完成、结果已校验 |

这些小物件全部输出透明 256px WebP，浅色和深色页面共用同一文件。

角色补充状态 `annotate`、`dict`、`offline`、`sleep`、`read-sofa`、`badge`
同步完成透明化；`badge` 使用主形象头肩裁切而不是模型全身图。

### 4.4 明确禁止区域

- 论文标题、摘要、正文、译文、公式、图注和表格内部；
- 查词结果卡；
- 引用预览卡；
- 批注编辑框、选区浮层和段尾气泡；
- 双篇论文正文栏；
- 维护工具弹窗；
- 工具按钮、焦点控件内部或会遮挡键盘焦点的位置。

## 6. 接入顺序与门禁

1. 从 `wan27-image-pro-character-suite-v1` 选六张基准，逐张检查人物—道具接触与遮挡。
2. 提取透明背景，导出 512px 运行时 WebP；透明边缘不得切掉手、书页、放大镜手柄或尾巴。
3. 先接入 `loading-wait` 单点，验证 Sprite 加载、亮/暗、375px、减少动态和 L2。
4. 接入 `success` 与 `error-cry`，验证完成/失败状态切换不会破坏任务状态。
5. 接入 `thinking`、`search-empty`、`stack`，每次只改展示层。
6. 每个状态补真实 DSH 截图、console 0、资源 HTTP 200、无布局位移。
