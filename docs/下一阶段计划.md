## P0 质量与可信度

**状态：✅ 2026-10-20 已完成（D-050 / D-051）。** 三篇回归集全绿；复核默认自动应用通过校验的修订，问题面板仅作追溯；旋转密集表优先用 Pdfium 文字层确定性重建 32 列，视觉切片只作兜底；公式自动重试，手动修正仅作高级兜底；版本可核验但不阻塞。下一步进入 P1。

1. **建立固定回归集**：至少覆盖 Sensors（MDPI 单栏+侧栏）、Plague（页顶双栏+全宽图+旋转表）、PLOS（双栏+Supporting）三篇；每篇保存页数、块类型、参考文献编号、图表公式数量、关键段首句的期望值。
2. **复核问题日志**：算法自动应用通过校验的修订并做二次 repair；剩余问题可在日志中定位原段、查看原文/现译/回译/建议，但不作为用户必做步骤。
3. **整页旋转密集表**：优先从 Pdfium 阅读顺序文字层确定性重建表格；失败后再按 1600px WebP + 纵向重叠切片做视觉兜底；仍失败才保留原表。
4. **公式可信度**：低置信度/括号不平衡的 LaTeX 只提供警示，不进入提问上下文；用户可手动校正并保存。
5. **版本核对**：阅读页版本徽标从“未核验”推进到可手动选择 VOR/录用稿/预印本；所有问答继续自动带版本戳。

## P1 多文本并行/对比

**状态：✅ 2026-10-20 已完成（D-052 ~ D-064）。**

已做：

1. **多篇综述入口**：主界面第三条通栏入口，与两条单篇入口分开；选 2–3 篇后进入 `shell.overlay` 全宽视图，不挤在 343px 右栏里。
2. **精简语料层**：`src/digest.js` 把每篇压成摘要 + 章节 + 关键段 + blockId（单篇 ≤4800 字符），2–3 篇一起交给模型，不重传全文。
3. **证据表**：研究问题 / 对象与数据 / 方法 / 指标 / 主要结果 / 局限 / 与问题的关系；每格必须带 blockId，无依据写「未找到」，不把“设定不同”说成“结论冲突”。
4. **引用双篇对照**：阅读页 `← 引用 [n]` + `双篇对照`；固定 A=引用方、B=被引论文，证据只能来自 B，支持度四档，无有效证据降级为「证据不足」。
5. **多篇批注同一次发送**：批注条读回全库未发送批注，显示 `N 个批注 · M 篇论文`；宿主摘要按论文分组，模型经 `doraemon_read_annotations` 取完整包。
6. **返回与位置**：阅读位置按 jobId 记忆；引用跳转保留 `fromCitation`，可回到引用处。
7. **对照工作台 v2（D-053）**：左侧 8 两篇论文全文（选区批注、蓝链、轻量引用卡），右侧 3 工作台（对话 + Markdown + 命令）；对照表/逻辑图/结构图/汇总走右侧「产物」窄轨 → 小列表 → 浮窗；`compare/ask` 直接读两篇档案回答。
8. **论文栏能力同步（D-054）**：原文/中文/对照三态、术语表弹窗、逐字 `.dpr-cmpMark` 高亮；产物浮窗可拖动/缩放；工作台消息刷新后恢复。
9. **三项收口（D-060）**：公式用 matplotlib mathtext 预渲染 SVG（非 KaTeX）；32 列 `tableText` 确定性拆成 HTML 网格；真实引用卡 → 查询 → 取回 → 阅读页的 `fromCitation` 全链 L2 已通过。
10. **依赖取舍与剩余三项（D-061）**：KaTeX 0.19.0 随包 vendoring（MIT，558 KB），公式改为 KaTeX 排版；同篇本地版本差异（段落级 LCS）；本地归档 `compare-archives/`（可被网盘/Git 同步）；术语保存后真正重译并 L2 通过。
11. **受限模型数据图 + 云同步退出（D-062）**：模型只能选表格/档案里已有数字，每点带 blockId/quote，校验不过就丢弃；云同步不做，目标为 DSH 桌面端。
12. **自由概念图 + 折线数据图（D-063）**：概念图允许模型组织问题、方法、证据、结果、局限、缺口与研究机会；论文事实节点必须有 `jobId/blockId/quote`，无锚点的跨论文归纳以虚线标「模型归纳」，无锚点数字节点丢弃。数据图新增折线分支，仍只使用可逐点回原文的数字。
13. **真实 VOR/预印本 + 桌面安装（D-064）**：同题两个真实本地镜像分别标成 VOR / 预印本，双栏徽标与版本差异两列均通过 L2；desktop profile 通过桌面端应用内「插件 → 添加插件」安装并启用，新建会话可打开「论文阅读器」主界面。

**明确边界：**

1. **自由位图生成不做**：无出处图片会削弱“真实性优先”；需要解释关系时用概念图，需要数字时用有出处数据图。
2. **版本差异是段落级确定性候选**：不做语义等价判断；文本不完全相同的段落会同时出现在左右，最终判断仍需人核对。
3. **系统级摘要/版本合并后置**：当前能比较同题两个本地副本，尚未自动从出版商抓取 VOR 或自动把 VOR/预印本合并成一个论文实体。

## P2 论文术语即时查词

**状态：✅ 2026-10-20 核心闭环完成（D-065）。**

已做：

1. 单篇阅读页和双篇 `PaperPane` 选区浮层新增「查词」，原批注入口保留。
2. 选中词/缩写/短语后调 `POST /jobs/<id>/term-lookup`；宿主重读当前 MirrorDoc，按 blockId 取当前段与当前句。
3. 优先查论文术语表和论文内缩写定义，覆盖 `full name (ABC)` 与 `ABC full name` 两种形式。
4. 缺少可靠中文解释时才调用模型；模型只输出词型、全称、本文语境义、简短补充、句中的作用、置信度与警告。
5. 临时查词卡显示来源、置信度、当前句、页码/章节/blockId，可定位原段；Esc/关闭按钮收起。
6. 查询缓存只在宿主进程内存中，最多 200 条，重启清空；不创建 `vocabulary.json` 或任何学习数据。
7. `src/terms.js` 提供纯逻辑与提示词；L0 覆盖选区长度、分类、句界、缩写定义、术语表优先和低置信降级。

质量收口：

1. 句界跳过 `e.g.` / `i.e.` / `et al.` 等缩写点；
2. 同一缩写保留最多 6 个候选，优先当前段定义并提示歧义；
3. 560px 暗色窄屏通过；
4. desktop link 版通过 `--cdp` 全链实测。

**边界**：如未来引入本地词典，必须先核许可证，并继续把“词典/论文定义”与“模型补充”分开；不恢复生词本。
