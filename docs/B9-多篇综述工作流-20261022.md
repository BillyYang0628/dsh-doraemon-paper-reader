# B9 多篇综述工作流

## 1. 目标

B9 把“多篇综述”从并排打开论文，升级为三条可验证的研究任务：

| 模式 | 论文数 | 目标 |
|---|---:|---|
| 2 篇方法对照 | 正好 2 篇 | 先判断是否可比，再比较任务、数据、方法、指标和结果 |
| 3 篇研究缺口 | 正好 3 篇 | 聚类共同覆盖、设定差异、真正冲突和未验证空白 |
| 综述报告 | 2–3 篇 | 从有 blockId 的证据表生成背景、路线、比较、争议、缺口和下一步 |

原有多篇双栏全文、批注、蓝链、概念图、数据图和归档能力保留。

## 2. 可比性预检

打开对照前，插件先做确定性预检：

- 检查任务要求的论文数量；
- 同 DOI、同 arXiv 或同标题识别为同一论文副本/版本；
- 用标题、摘要、章节概括和关键段计算共同研究词与相似度；
- 输出 `comparable / limited / not-recommended`；
- 对“不建议直接对照”不调用对照模型，提示返回重新选文；
- 用户可显式选择“仍然尝试对照”，报告仍保留低可比性警告。

预检是选文守门，不是学术质量结论。

## 3. 证据模型

七字段表格继续要求每个单元格给 blockId。

B9 新增两类跨论文对象：

### 跨论文关系

- `shared`：共同覆盖
- `difference`：设定/方法差异
- `conflict`：真正相反
- `complement`：互补关系

每条关系必须有至少一条来自已选论文的有效 blockId；无锚点关系直接丢弃。

### 研究缺口

每条缺口只有两种合法形态：

1. `grounded`：至少两篇不同论文都有有效 blockId；
2. `model-inference`：明确标为模型归纳，可附相关原文、验证实验和查新状态。

只有一个锚点又未声明模型归纳的“缺口”会被拒绝并写入警告，不进入报告事实区。

## 4. 证据型报告

新增 `POST /compare/survey-report`，从已校验表格确定性生成 Markdown：

- 论文范围与可比性；
- 只包含 grounded 单元格的原文对照；
- 有 blockId 的跨论文关系；
- 有至少两篇论文证据的研究缺口；
- 单列的“模型归纳（需人工验证）”；
- 已定位、未定位、未找到和待核对文字统计。

报告事实区不会写入手动改过但未重新锚定的表格内容。用户编辑单元格后，该格标记为 `manual=true / grounded=false`，进入待核对区。

## 5. 模型输出稳定性

对照模型结构变大后，真实回归捕获过一次非法 JSON：

```text
Expected ',' or '}' after property value in JSON at position 1672
```

处理：

- 首次 JSON 结构错误自动重试一次；
- 连续失败返回 HTTP 200 `kind=table-error`，附 `retryable=true` 和诊断；
- 客户端显示中文恢复建议，不再暴露裸 500；
- 论文、批注、缓存和已有产物不受影响。

## 9. 边界

- 可比性预检是基于标题、摘要和关键段的确定性启发式，不替代研究者判断；
- 当前紧凑档案可能没有论文结果表数值，报告会明确写“未找到”，不会补造；
- 研究缺口优先要求两篇以上原文锚点；没有满足条件的缺口时会明确标为模型归纳；
- 缺口的全网新颖性搜索尚未自动执行，报告统一显示“未查新”；
- 三篇上下文比两篇更容易触发模型结构错误，当前只自动重试一次并提供可恢复降级。
