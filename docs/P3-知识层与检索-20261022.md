# P3 知识层与检索

## 1. 目标

P3 把分散在作业目录里的正文、批注、问答记录、翻译、术语、引用和综述报告，统一成可搜索、可追溯的本地知识层。

所有结果必须保留：

```text
jobId + blockId + page + section + sourceType
```

没有 blockId 的内容不能伪装成论文事实。

## 2. 本地知识索引

索引文件：

```text
$DSH_HOME/doraemon-paper-reader/knowledge/index.json
```

覆盖来源：

| 来源 | 实际内容 |
|---|---|
| `text` | MirrorDoc 标题、摘要、标题块、正文和题注 |
| `annotation` | 单篇批注，以及已发送批注批次中的问题 |
| `qa` | 对照工作台已完成的问答；问题与回答都保留关联论文和回跳锚点 |
| `translation` | `translations.zh.json` 的中文标题、摘要和块译文 |
| `term` | `glossary.json` 的术语、中文解释、锁定和来源块 |
| `citation` | MirrorDoc 参考文献及 DOI/arXiv |
| `report` | 本地对照归档报告 |

索引指纹包含：

- MirrorDoc 与 paper-summary；
- annotations.json；
- translations.zh.json；
- glossary.json；
- 批注批次；
- `knowledge/qa.jsonl`；
- 对照归档。

源文件变化后，下一次搜索会自动重建，不要求用户手动点“重建索引”。手动重建用于诊断。

## 3. 跨论文检索

检索算法：

- 英文词与中文二元组；
- 文档频率和本地 IDF；
- 标题/章节字段加权；
- 精确短语加权；
- 来源权重：批注和术语优先，其次报告/引用，正文与译文作为主体；
- 结果按论文聚合；
- 结果片段围绕首个命中位置截取。

支持筛选：

- 正文；
- 批注；
- 问答记录；
- 译文；
- 术语；
- 引用；
- 综述报告。

点击结果直接打开阅读页对应 blockId。

对照工作台每次问答完成后自动追加到 `knowledge/qa.jsonl`；下一次搜索会根据文件指纹自动刷新
`qa` 条目，不需要手动重建索引。

固定真实查询集：

```text
MobileViT
plant disease edge device
supply chain shock detection
antimicrobial resistance
research data citation rate
IoT sensor actuator
tabular embeddings
```

七条查询均返回结果，Top-20 结果 `blockId` 覆盖率 100%。

## 4. 证据型知识问答

`POST /knowledge/answer` 先执行本地检索，再把最多 18 条带锚点材料交给模型整理。

约束：

- 只回答问题，不自动写综述或审稿意见；
- 每个事实后标 `[P1 b0002]`；
- 没有材料时明确写“当前检索未找到”；
- 模型不可用或无凭据时，本地结果仍然可查看；
- 返回来源列表供点击回原文。

## 5. 引用图谱

`GET /jobs/:id/citation-graph`：

- 中心节点为当前论文；
- 出边来自当前论文参考文献；
- 入边来自本地论文参考文献对当前论文的反向匹配；
- 本地命中节点可直接打开阅读页；
- 出边缺少 blockId 时用虚线；
- 外部施引关系暂未做全库检索；
- 外部 OA 状态未核验时明确显示“未核验”。

统计口径分开：

- 本地施引论文数；
- 本地引用边数；
- 出边数；
- 本地出边数。

真实 MobileViT 图谱实测：

- 出边 63；
- 本地出边 0；
- 本地施引论文 5；
- 本地引用边 217；
- 图谱请求约 0.36 秒。

## 6. 导出

接口：

```text
GET /jobs/:id/export?kind=annotations-md
GET /jobs/:id/export?kind=annotations-json
GET /jobs/:id/export?kind=glossary-csv
GET /jobs/:id/export?kind=citations-md
```

导出前检查：

- 批注是否有原文片段；
- 批注片段是否有 blockId；
- 术语是否有来源块；
- 参考文献是否有 blockId。

告警通过响应头回传，并在知识中心显示，不静默省略。

## 7. 阅读档案

阅读页每 30 秒以及切换章节/隐藏页面时更新：

```text
readingSeconds
lastBlockId
lastPage
lastSection
visitedBlockIds
```

档案保存在：

```text
$DSH_HOME/doraemon-paper-reader/knowledge/profile.json
```

知识中心聚合：

- 总阅读时长；
- 有阅读记录的论文数；
- 未发送批注；
- 译文复核待处理问题；
- 最近阅读位置；
- 下一行动作。

## 9. 边界

- 当前检索是本地词法召回，不使用外部 embedding 服务；
- 证据问答的模型只整理本地命中，不主动联网；
- 引用图谱的外部施引未做全库检索，只展示本地已知关系；
- 外部节点 OA 状态未核验时明确显示未知；
- 阅读时长是前台可见时间的保守估计，不是行为追踪；
- 索引是全文与元数据索引，不改变 MirrorDoc、批注或翻译原文。
