## 3. 首轮红灯结果

### 3.1 R-005 / R-011：Algorithm 1 结构错误已稳定复现

来源：

- `工具/gen/B0-20261021/structure-aiot/report.json`

结果：

- `b0104`：Algorithm 1 题注，类型 `caption`。
- `b0105`：`BEGIN`，错误类型 `heading`。
- `b0106`：12 条伪代码步骤全部压成一个 `paragraph`。
- `b0107`：`END`，错误类型 `heading`。
- 结构审计检出 2 个可疑 heading 和 1 个连续编号步骤 paragraph。

这与用户实测一致，后续 B3 以该 fixture 作为第一组结构红灯。

### 3.2 R-014：sticky 目录被阅读栏遮挡已复现

来源：

- `工具/gen/B0-20261021/navigation/report.json`

滚动后实测：

- 阅读栏底部 `barBottom = 156px`
- 目录顶部 `outlineTop = 74px`
- 遮挡量约 `82px`

后续 B2 必须让目录 top 动态跟随工具栏下沿，不能用固定 `top:12px`。

### 3.3 R-015：切换页面后回到顶部已复现

同一报告：

- 切走前 `scrollTop = 1400`
- 从主界面重新打开后 `scrollTop = 0`

现有 scroll storage 意图未生效。B2 需要区分组件卸载、重新 fetch doc、targetBlockId 定位与 keepMounted。

### 3.4 R-021：独立文档管理入口当前不存在

来源：

- `工具/gen/B0-20261021/library/report.json`

结果：

- `libraryEntry: false`
- 当前主界面只有最近论文 `7` 项、PDF 入口、查询入口和多篇综述。
- 文档管理、批量导入和按需转义需要作为新增产品能力实现。

### 3.5 R-018：表格结构存在高风险基线

AIoT 样本 5 个 table block：

- Table 1：389 字符
- Table 2：264 字符
- Table 3：622 字符
- Table 4：259 字符
- Table 5：304 字符
- 5 个 `tableText` 都没有显式换行。

这还不能单独证明“只提取了部分行”，但说明当前结构化数据无法直接证明行完整性。B4 必须增加原表行数/解析行数/退化行对照。

### 3.6 R-013：分隔符能力基线

当前六个 corpus 样本的 MirrorDoc 中，`separator/divider/rule` block 数均为 0。

注意：这可能表示“原文没有可识别分隔线”或“解析器不支持分隔符”，不能直接把所有 0 判成失败。B3 需要打开原页，对内容横线与表格内部线分别标注后再定性。
