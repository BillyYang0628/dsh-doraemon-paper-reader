# UI 基础系统与插画动效清单

> 本文定义 P5 的 UI 基础设施、插画资产清单和动效边界。
> 视觉语言仍以 [`界面风格-v0.md`](界面风格-v0.md) 为准；本文不改变功能协议、数据模型或交互流程。
>
> **2026-10-20 修订**：本文 §5 的 14 类姿态保留为候选池。按完整页面与真实状态重新收紧后的
> 页面矩阵、身份锁、首批优先级、标准化提示词和验收闸门，以
> [`角色插画标准-v1.md`](角色插画标准-v1.md) 为准。运行时仍不使用 `.gif`。

## 1. 实施边界

### 1.1 当前 UI 基础系统

UI 落地分两层，当前均已生效：

- **D-069 基础层（纯 CSS 覆盖）**：先建立 token 与共享表面，不改变 DOM、事件、状态、API、缓存或持久化；
- **D-070 页面层（用户授权后的展示性 DOM 迁移）**：主界面、PDF 入口、加载页、阅读页和对照工作台按已确认样张增加 wrapper 与信息层级；
- **D-072 配色层（纯 token 派生）**：用宿主 base/link/amber 生成暖米纸、奶油卡面、深海军蓝文字与暗色海军蓝层级，不新增容器字面色值；
- 页面层只改变“怎么展示”，原有按钮、处理器、状态机、API、缓存与持久化保持接线；
- 保留原有 `.dpr-*` 类名和 E2E 选择器；
- 所有容器颜色、边框、阴影和文字色都从 DSH 宿主 token 派生；
- 字面色值仍只用于既有的像素图标与插画；
- 页面专用样式可以继续覆盖通用层，不形成第二套组件实现。

### 1.2 安全原则

1. 每次 UI 改动先跑 `npm test` 建立基线。
2. 视觉层改动后必须复跑 L0、受影响的 L2 和真实 DSH 页面。
3. 不为了视觉效果删除控件、隐藏失败路径或改变键盘操作顺序。
4. 插画先出预览；未经确认不批量接入。
5. 动效不可阻塞输入，不覆盖正文，不改变焦点位置。

## 3. 共享视觉规则

| 层 | 规则 |
|---|---|
| 页面 | 宿主底色 + 极淡 8px 点阵；阅读容器不铺重纹理 |
| Hero | 暖奶油卡面、虚线内框、像素贴纸式主形象 |
| 入口卡 | 第一入口用浅蓝软底，第二入口用奶油卡面；左侧图标、右上序号、正文左对齐 |
| 主按钮 | 深蓝实底 + 白色文字 + 强边框和硬边阴影；禁用态整体降透明度 |
| 次按钮 | 宿主背景层、弱边框；hover 只改变表面与边框 |
| 输入 / 拖放 | 焦点可见；拖入态与 hover 使用同一语义 |
| 阅读器 | 工具栏更紧凑，正文维持长文行高；不把阅读区做成重卡片 |
| 状态 | 失败带明确文案与第二重图标；加载/成功不能只靠颜色区分 |
| 动效 | 仅使用 transform/opacity；遵循 `prefers-reduced-motion` |

## 4. 插画与动效总原则

### 4.1 出场规则

大肥鱼只出现在有人味的时刻：

- 首次进入、空态、局部失败；
- 长任务进行中；
- 导入成功；
- 网络或服务不可用。

禁止出现在：

- 论文正文中间；
- 表格、公式、数据图和概念图内部；
- 选区浮层、查词卡、批注编辑框；
- 双篇对照的论文正文栏；
- 常驻工具栏或遮挡键盘焦点。

一屏最多一个吉祥物姿态，同一状态不混用画风档位。

### 4.2 当前运行边界

当前静态资源路由只允许 `.webp / .png / .jpg / .jpeg / .svg`，**不允许 `.gif`**。

因此现阶段推荐：

- 静态姿态：透明 WebP/PNG；
- 像素动效：PNG 精灵图 + CSS `steps()`；
- 若必须追求单文件动画：优先动画 WebP；
- 不把 GIF 作为默认交付格式。GIF 透明边缘、文件体积和颜色抖动都更差；如确实需要 GIF，必须先单独修改 MIME 白名单和 L0 安全测试，不能先把 `.gif` 文件塞进 `assets/`。

### 4.3 动效预算

| 项 | 规则 |
|---|---|
| 帧率 | 像素动效 8–12 fps |
| 张数 | 循环动效 4–6 帧；一次性成功动效 6–8 帧 |
| 逻辑尺寸 | 160–240px；源图按 2× 输出 |
| 文件 | 单张静态 ≤ 160 KB；单份动效资源 ≤ 500 KB |
| 次数 | 成功动效播放 1 次；加载/思考循环到任务结束 |
| 降级 | 减少动态时显示首帧或静态关键帧 |
| 卸载 | 页面或任务状态结束后停止动画，不后台持续运行 |

## 5. 全插件插画清单

优先级：**P0 核心体验；P1 常用增强；P2 可选；P3 不建议进入运行时。**
实际首批与页面触发条件见 [`角色插画标准-v1.md`](角色插画标准-v1.md) §4～§5。

| ID | 页面 / 时刻 | 类型 | 优先级 | 用途与行为 |
|---|---|---|---|---|
| `badge` | 页签 / 插件图标 | B 静态 | P1 | 半身徽章；是否替换当前抽象 `icon.svg` 待确认 |
| `hello` | 主界面、首次引导 | C 静态 | P0 | 已存在 `mascot-hello-smile-c.webp`；作为欢迎与路径页主形象 |
| `read-lying` | 阅读页无有效 job / 文档加载空态 | C 静态 | P0 | 趴着读论文；替代纯错误文案，但加载很快时不闪出 |
| `read-sofa` | README、引导长页 | C 静态 | P2 | 更适合文档和大插图，不建议常驻插件页面 |
| `stack` | 多篇综述空库 | C 静态 | P1 | 抱一摞厚重蓝色童话书；只在没有可选论文时出现 |
| `loading-wait` | PDF 抄写、版面提取、渲染 | P 动效 | P0 | 抱书等待 + 沙漏；4–6 帧循环；替代当前重复使用欢迎图 |
| `thinking` | 信息查询、对照档案、引用分析、翻译/复核 | P 动效 | P1 | 托腮 + 三点；4–6 帧循环；只在模型任务区域小尺寸出现 |
| `success` | PDF 导入完成 | P 动效 | P0 | 举起厚重蓝色童话书 + 星星；6–8 帧播放一次，结束后停在完成帧 |
| `error-cry` | PDF 提取失败、阅读页整体加载失败 | P 静态 | P0 | 抱膝流泪；错误文案与重试按钮必须同时存在 |
| `search-empty` | 信息查询无结果 | P 静态 | P0 | 放大镜里为空；与“候选列表为空”状态绑定 |
| `offline` | 网络请求失败、API 不可达 | P 静态 | P1 | 抱着断线；仅用于连接失败，不用于论文内容错误 |
| `annotate` | 批注首次引导 | P 静态 | P2 | 拿荧光笔划重点；仅在一次性帮助里出现 |
| `dict` | 查词首次引导 | P 静态 | P2 | 一手词典、一手指词条；查词结果卡本身不放插画 |
| `sleep` | 长时间后台任务已离开页面 | C 静态 | P2 | 趴书睡着；若“loading-wait”已覆盖后台提示则不重复制作 |

## 6. 页面状态映射

### 6.1 主界面

| 状态 | 资产 | 备注 |
|---|---|---|
| 默认 / 首次进入 | `hello` | 现有资产即可 |
| 有最近论文 | `hello` | 不因列表出现而切换姿态，避免页面跳动 |
| 无最近论文 | `hello` | 不额外加第二张空态图 |
| 环境与存储弹窗 | 无 | 工具型弹窗保持克制 |

### 6.2 PDF 导入

| 状态 | 资产 | 备注 |
|---|---|---|
| 未选择文件 | 小尺寸 `hello` | 保持路径连续性 |
| 已选择、未开始 | 小尺寸 `hello` | 文件选择和主按钮承担反馈 |
| 上传 / 排队 / 提取 / 渲染 | `loading-wait` 动效 | 阶段列表仍为主信息 |
| 完成 | `success` 一次性动效 | 完成后提供“打开阅读页” |
| 失败 | `error-cry` | 必须显示错误原因、重试/换文件 |
| 返回后台继续 | `loading-wait` 静态帧 | 不播放高干扰循环；切回页签再恢复 |

### 6.3 信息查询

| 状态 | 资产 | 备注 |
|---|---|---|
| 初始表单 | `hello` 或纯表单 | 优先纯表单，减少干扰 |
| 搜索中 | `thinking` | 放在结果区，不遮挡输入 |
| 有候选 | 无 | 候选卡优先 |
| 无结果 | `search-empty` | 同时解释可补充哪些字段 |
| 网络失败 | `offline` | 与检索无结果区分 |

### 6.4 单篇阅读

| 状态 | 资产 | 备注 |
|---|---|---|
| 无 job / 打开失败 | `read-lying` | 只在整页无法阅读时出现 |
| 文档加载 | 骨架屏 | 不出现大幅插画 |
| 翻译中 | 工具栏进度 + `thinking` 小图可选 | 正文保持原文可读 |
| 翻译失败 | 行内错误条 | 不替换正文，不弹大图 |
| 复核问题 | 审计面板 | 用图标与表格，不用吉祥物 |
| 查词 | 查词卡 | 不用吉祥物占位 |
| 蓝链引用 | 引用卡 | 不用吉祥物 |

### 6.5 多篇综述与引用

| 状态 | 资产 | 备注 |
|---|---|---|
| 综述空库 | `stack` | 引导先去导入论文 |
| 选论文 | 无 | 表单与勾选卡 |
| 生成档案/对照表 | `thinking` 小图 | 只在右工作台状态区 |
| 对照失败 | `error-cry` 或纯错误卡 | 大图仅在整层失败时使用 |
| 双论文正文 | 无 | 绝不在论文栏放装饰 |
| 引用关系 | 无 | 用 A/B、证据标签和连线表达 |

### 6.6 维护与全局错误

| 状态 | 资产 | 备注 |
|---|---|---|
| 维护统计加载 | 骨架/文字 | 不用插画 |
| 修复 Python 成功 | 轻量 toast | 不需要动画角色 |
| 网络断开 | `offline` | 重连按钮 |
| 403 / 风控 / 禁止访问 | `error-cry` | 文案说明停止抓取与可选合法渠道 |

## 7. 动效清单

### 7.1 推荐制作

| 动效 | 帧数 | 循环 | 触发 | 停止 |
|---|---:|---|---|---|
| `loading-wait` | 4–6 | 是 | PDF 抄写、版面处理 | 任务完成/失败/页签卸载 |
| `thinking` | 4–6 | 是 | 模型分析、检索、对照 | 请求结束/取消 |
| `success` | 6–8 | 否 | 导入完成 | 播放一次后静态 |

### 7.2 CSS 微动效即可，不单独出 GIF

- 加载点呼吸；
- 图标按压位移；
- 进度点闪烁；
- 卡片 hover/active；
- 段尾批注气泡；
- 跳转后的两次高亮。

这些动效已经可由 CSS 完成，不增加图片请求。

### 7.3 不建议做 GIF

- 主界面常驻招手；
- 每个按钮 hover 角色动作；
- 阅读页滚动跟随角色；
- 长时间循环哭泣；
- 闪烁、抖动、频闪类背景。

## 8. 资产合同

### 8.1 命名

```text
mascot-<pose>-<expression>-<tier>.webp
mascot-<pose>-<expression>-<tier>-sprite.png
```

示例：

```text
mascot-loading-wait-focus-P-sprite.png
mascot-success-smile-P-sprite.png
mascot-error-cry-cry-P.webp
```

### 8.2 静态图

- 透明背景优先；米白卡底由 CSS 提供；
- 1:1 画布，主体四周至少留 8%；
- 源图 1024 或 2048，界面按 2× 整数倍缩放；
- 不得烘入文字、边框、按钮、阴影或 UI；
- 必须通过 alpha 边缘和缩小后细节检查。

### 8.3 动效图

- 所有帧共用同一画布、角色中心和脚底基线；
- 不改变发色、瞳色、兜帽、披风、鲸鳍耳、呆毛、鲸尾；
- 循环帧的首尾姿态必须闭合；
- 一次性动作的首帧与静态入口一致；
- 动画帧不得包含文字、标点、水印或场景道具。

### 8.4 无障碍

- 有意义插画必须有状态化 `alt`；
- 纯装饰重复图使用空 `alt` 或隐藏；
- 加载状态由 `role="status"` 提供文字反馈，图片不能是唯一信息；
- 减少动态时用静态首帧；
- 动画区域不能改变布局尺寸或遮挡焦点。

## 10. 验收

插画接入某一状态前必须同时满足：

- 角色身份一致；
- 缩到实际尺寸仍可辨认；
- 亮暗主题都有合理托底；
- PNG/WebP 实际加载；
- `prefers-reduced-motion` 有静态替代；
- 不遮挡、不移动主要操作；
- 现有 L0 和对应 L2 全绿；
- 同页没有第二只吉祥物或第二套画风。
