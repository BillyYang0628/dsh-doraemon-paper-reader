# P4 工程化与发布

## 1. Python 受管环境

插件不再直接依赖 PATH 上的全局 Python 包。

- 环境目录：`$DSH_HOME/doraemon-paper-reader/python-env/`
- Windows 解释器：`python-env/Scripts/python.exe`
- 依赖：`工具/pdf-pipeline/requirements.txt`
- `requirements` 内容哈希写入 `python-env/.doraemon-runtime.json`
- pip cache：`$DSH_HOME/doraemon-paper-reader/python-pip-cache/`
- 临时目录：`$DSH_HOME/doraemon-paper-reader/python-tmp/`

首次需要 PDF/公式/表格视觉任务时自动创建；也可手动：

```powershell
npm run setup:python
npm run benchmark:pdf
```

运行逻辑：

1. 若受管解释器存在、依赖哈希一致、`pdfplumber/pypdfium2/PIL/matplotlib` 探测通过，直接复用；
2. 否则用 `DPR_BASE_PYTHON`、`DPR_PYTHON`、`D:\Python\python.exe` 或 PATH 基础解释器创建 venv；
3. 在 venv 内安装 requirements；
4. 失败时保留明确错误，不静默回退到一个未知的全局包集合。

## 2. 环境与存储维护

主界面「环境与存储」入口提供：

- 论文作业数量/大小；
- 可重建缓存文件数/大小；
- 批注批次大小；
- Python 运行时状态和路径；
- 「准备/修复 Python 环境」；
- 「清理可重建缓存」；
- 刷新统计。

### 可清理

- `comparisons/`：对照结果缓存；
- `citation-analyses/`：引用概览缓存；
- `citation-cards/`：引用卡缓存；
- 每篇作业的 `vision-cache/`；
- 每篇作业的 `translations-cache.json`。

### 永不自动清理

- `jobs/*/mirrordoc.json`
- `jobs/*/original.pdf`
- `jobs/*/assets/`
- `jobs/*/annotations.json`
- `jobs/*/glossary.json`
- `annotation-batches/`
- `compare-archives/`

清理接口只接受固定 scope 名，不接受任意路径。

## 3. 后台任务取消

阅读页翻译、复核、公式识别和表格整理均有取消入口：

```text
POST /doraemon-paper-reader/api/jobs/<jobId>/cancel-task
{ "kind": "translation|review|formula|table" }
```

取消策略：

- 不强行中断正在进行的单个模型请求；
- 当前请求结束后不再派发下一批；
- 已写入的译文/缓存保留；
- 翻译取消不修改原文可读性；
- 复核取消不改写现有译文；
- 状态变为 `cancelled`，前端停止轮询。

## 4. 安装

### dev profile

```powershell
dsh plugin --profile dev add link:D:\DSH-Plugins\dsh-doraemon-paper-reader
```

本机已安装，代码更新后重启 dev Host 即可。

### desktop

使用 DSH 桌面端「插件 → 添加插件」，填写：

```text
D:\DSH-Plugins\dsh-doraemon-paper-reader
```

安装后点「立即启用」。不要手改 desktop profile，也不要在 profile 目录运行 pnpm。

### 发布包

```powershell
npm run package:release
```

生成：

```text
dist/dsh-doraemon-paper-reader-0.2.0.tgz
dist/dsh-doraemon-paper-reader-audit-lab-0.2.0.tgz
dist/RELEASE_NOTES-0.2.0.md
dist/release-manifest.json
dist/SHA256SUMS.txt
```

工作树有未提交改动时，正式打包会拒绝；只生成本地候选用：

```powershell
npm run package:candidate
```

`npm run verify` = Node L0 + Python PDF 单测 + 文档链接 + 本机真实 PDF 回归。
不需要真实论文样本的 CI 使用 `npm run verify:offline`。

两个包的目的不同：插件 tgz 供 DSH 安装；audit-lab tgz 只包含 PDF 管线、审计器、
案例与实验文档，供用户自行迭代。详见 `docs/搭建与发布.md`。

## 5. 升级

### link 安装

仓库代码就是运行代码：

1. 更新源码；
2. 执行 `npm run verify`；
3. dev：重启 dev Host；
4. desktop：关闭并重新打开 DSH 桌面端；
5. 新建会话验证「论文阅读器」入口。

### tgz 安装

1. 保留旧版本 tgz；
2. 在插件管理页卸载旧版本；
3. 安装新 tgz/目录；
4. 新开 session 验证。

版本号必须递增。当前发布版本为 `0.2.0`。

## 6. 卸载

### dev

```powershell
dsh plugin --profile dev remove dsh-doraemon-paper-reader
```

### desktop

在桌面端「插件」页选中 `dsh-doraemon-paper-reader`，执行卸载。

卸载插件不会删除 `$DSH_HOME/doraemon-paper-reader/` 中的论文、批注和归档。需要彻底清理数据时，必须由用户显式确认后手工处理；插件不提供“一键删全部论文”。

## 7. 回滚

- 保留前一个已验证的 tgz；
- 卸载当前版本；
- 安装旧 tgz；
- 若是 link 安装，可切换 Git 标签或提交后重开 DSH；
- 数据库/文档格式变更必须向前兼容；当前 jobs、annotations、glossary、compare archive 都有版本字段。
