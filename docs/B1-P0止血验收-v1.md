# B1 P0 止血验收 v1

> 对应 [`问题处理方案-v1.md`](问题处理方案-v1.md) 的 B1：R-002、R-007、R-004。

## 1. 完成项

### R-002 拖放遮罩

- 在 `window` 捕获阶段识别插件 pane：优先看事件目标，找不到时按指针坐标命中 pane 矩形。
- 插件内的 `dragenter` 不再触发 DSH 宿主全局拖放遮罩。
- 非 drop 区的 `dragover/drop` 被插件边界接管，避免浏览器直接打开 PDF。
- `.dpr-drop` 内的原有 React `dragover/drop` 链保留，不绕过文件选择与上传逻辑。

### R-007 引用 400

- 客户端在打开引用卡前检查参考文献原文；缺失时直接显示业务错误，不发请求。
- 服务端 `citations/resolve` 和 `citations/analyze` 对空原文/空编号返回 `kind=invalid`，不再用裸 HTTP 400 表达可恢复业务问题。
- 引用卡片识别 `invalid` 响应并展示可读错误。

### R-004 原版页入口

- “原版 P.n”从 `target=_blank` 链接改为插件内按钮。
- 点击后打开原页查看器，显示 `原页图像 / 当前页 / 总页数`。
- 支持上一页、下一页、新窗口打开、Esc、点遮罩关闭。
- 图像加载失败时显示“源页文件可能缺失”，正文、批注与引用仍可使用。
- 没有 `jobId` 时不再渲染无效页码入口。
