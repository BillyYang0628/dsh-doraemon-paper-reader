# B6：批注问答契约

## 1. 目标

闭合 R-016 / R-017：

- 先回答用户真正问的问题；
- 默认帮助理解，不把批注问答变成审稿；
- 解释、机制和论证链优先，批判只按明确要求或放末尾；
- 长回答必须先理解再重组，不能逐句同义改写；
- 明确区分论文原文、外部资料和模型分析；
- 纯原文模式不得夹带外部知识；
- 回答保留页码、blockId 或回跳链接。

## 2. 单一契约模块

新增：

```text
src/qa-contract.js
```

提供：

| 函数 | 作用 |
|---|---|
| `classifyQuestionIntent` | 识别术语、方法、图表、段落作用、灵感、批判和多问题 |
| `buildAnswerPolicy` | 合并 UI 证据模式、用户强制要求和意图 |
| `buildAnnotationContract` | 生成用户消息紧凑契约与工具完整契约 |
| `buildAnnotationToolPolicy` | 工具说明中的统一回答规则 |
| `buildQaSystemContract` | 对照工作台等纯原文问答复用 |
| `assessAnswer` | 检查直接回答、结构、复读、批判位置、证据边界和回跳 |

`annotations.js` 不再单独维护一套回答规则；工具返回同时带：

```json
{
  "answerPolicy": {},
  "qaContract": "B6 完整回答契约"
}
```

## 3. 意图与回答结构

| 意图 | 默认结构 |
|---|---|
| 术语解释 | 是什么 → 本文语境 → 作者为什么需要 |
| 方法理解 | 一句话目标 → 输入/处理/输出 → 设计理由 → 与全文关系 |
| 图表读数 | 结论 → 对应行/值 → 解释 → 外推边界 |
| 段落作用 | 本段功能 → 承接前文 → 推动后文 |
| 没有明确问题 | 核心内容 → 关键概念/论证链 → 与全文关系 → 短总结 |
| 寻找灵感 | 原文事实 → 1–3 个迁移点 → 验证资源 → 风险/未查新 |
| 明确要求批判 | 总体判断 → 证据化评价 → 作者局限与模型判断分开 |
| 多问题 | 先逐条回答，再做跨条目归纳 |

## 4. 证据模式

批注条新增“回答方式”：

- **默认精读**：可补充外部背景，但外部内容必须标来源；无联网时明确“未做外部核验”。
- **只根据原文**：只使用论文证据，不引入外部事实。

用户问题中的“只根据原文/不要使用外部资料”会覆盖 UI 设置。

证据模式写入批注包 `answerPolicy`，旧批注包没有该字段时自动默认为 `allow-external`。

## 5. 确定性评估

`assessAnswer` 检查：

- 第一段是否直接回答；
- 是否有标题、列表、表格或多段结构；
- 与原文的最长连续重合和复制比例；
- 未要求批判时，批判是否出现在回答前部；
- 是否有页码、blockId 或回跳链接；
- 纯原文模式是否出现外部资料；
- 外部问题是否声明“未核验/未查新”。

它不是语义裁判：

- 不自动证明事实一定正确；
- 不替代人工核对；
- 固定问题集仍配置 `mustMention` 和 `forbidden` 作为轻量语义门禁。

当前结构阈值：

- 连续原文重合长度不超过 240 字符；
- 回答中原文复制比例不超过 42%；
- 未要求批判时，批判词项第一次出现在回答 58% 位置之前则标记；
- 以上阈值只用于提示明显退化，后续应按真实样本继续校准。

## 10. 边界

- 外部网页检索依赖宿主能力；当前评估环境没有联网工具，因此只验证“明确未核验”，不伪造查新。
- 7 个问题只覆盖当前精读场景，不代表所有学科和所有提问方式。
- 确定性评分只负责结构与明显退化；事实准确性仍需固定答案要点和人工复核。
- B7 的研究模式与灵感模式应通过 `buildAnswerPolicy` 增加策略，不另写一套提示词。
