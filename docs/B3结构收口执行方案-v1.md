## 1. 范围

B3 继续处理以下台账项：

- R-005：算法/特殊信息被误当正文；
- R-011：PDF 结构准确性需要持续审计；
- R-012：正文与标题字号/块类型误判；
- R-013：原 PDF 内容分隔线丢失。

本方案不处理表格单元格金标（R-018，B4），也不改中文翻译语义。

## 2. 审计先行规则

每个问题在修改解析算法前必须按以下顺序走完：

1. 写出可证伪的 audit rule；
2. 在现有语料上运行，保存 JSON/Markdown 证据；
3. 至少指出论文、页码、sourceId/blockId 和可观察现象；
4. 若规则没有命中，不进入修复，只保留为待观察；
5. 修复后对同一目录重跑审计，并用 `--baseline` 证明旧 finding 消失；
6. 同时跑原六篇 PDF 回归，出现新 rule 或 error 增量就回退。

“代码看起来应该有问题”不能作为修复依据。

## 3. 当前新增审计假设

### B3-A 跨栏行内混排

现象：

- Twitter 综述第 4 页左右栏正文出现在同一视觉行；
- 第 5 页搜索式框与相邻正文的阅读顺序也需要核实。

先新增行级诊断字段：

- `maxInternalGap`：同一视觉行内最大字符间隙；
- `internalGapCount`：明显超过正常词间距的间隙数量；
- `crossColumnLine`：全宽行同时包含栏间大间隙和两侧足量文字时为真。

Audit rule：

- `reading-order.cross-column-line`；
- severity 初始为 `error`；
- finding 必须带 page/sourceId/bbox/maxInternalGap/左右文字摘要。

只有该规则在旧语料上稳定命中后，才允许调整栏检测。

### B3-B 内容分隔线未进入阅读顺序

AIoT 第 10 页算法框存在 3 条水平线：

- y=265.1：算法题注上方；
- y=312.0：算法题注与步骤之间；
- y=512.0：算法结束后、下一标题前。

前两条位于算法块内部，第三条是跨块边界。解析结果必须区分：

- `separator` block：跨正文/标题/特殊块的内容边界；
- `specialRules` 元数据：特殊块内部保留的分隔规则；
- 表格/图像裁剪内部规则：不得重复生成正文分隔线。

Audit rule：

- `separator.unrepresented`；
- finding 带 page/bbox/前后块和上下文摘要；
- 修复后，同一规则应能识别对应 `separator` 或 `visualRules`。

### B3-C 假 heading 与字号跳变

除现有 `heading.false-positive` 外，新增跨模式检查：

- 同一 block 内字号中位数与 body 字号接近却标成 heading；
- paragraph 内存在多个 font size 聚类；
- 原文、中文、对照模式的块类型保持一致。

先在六篇语料上验证，再决定是否新增硬规则，避免把正常章节标题误报。

### B3.1 解析修复

- 栏检测在存在顶部全宽表/图时，按递增的探测起点寻找真实正文栏缝；
- 不把全宽表格行误拆成左右栏；
- 检测内容水平线并与 asset/special block bbox 去重；
- `MirrorDoc` 增加 `separator` block 和特殊块内部 rule 元数据；
- `separator` 不进入 outline、翻译单位或摘要正文。

退出条件：B3.0 的 error finding 清零；文本覆盖不下降；sourceIds 不重复、不丢失。

### B3.2 渲染与协议

- 阅读页、独立 HTML 渲染 `separator`；
- 原文/中文/对照模式保持相同位置；

- 页标、选区、批注、翻译、目录忽略 separator 的非正文属性；
- 增加 L0 与 L2 断言。

退出条件：真实阅读页可见分隔线；普通段落、特殊块和页标功能不退化。

## 5. 回归拒绝条件

以下任一情况出现即撤销本轮算法改动：

- 任意旧语料新增 error；
- 文本覆盖率下降或 `unassignedLines` 增加；
- 全宽表格/图片被拆成左右栏；
- 常规双栏参考文献页被误判为多栏；
- 表格内部线重复显示成正文分隔符；
- separator 进入目录、翻译任务或批注锚点；
- 页标数量与正文段落关系出现退化。

## 6. 完成定义

B3 收口不是“新增了一条规则”，而是：

1. 修复前有审计证据；
2. 修复后有同规则 before/after 差分；
3. 旧六篇无回归；
4. Twitter 跨栏混排和 AIoT 算法边界在真实阅读页可见；
5. R-012/R-013 状态有明确更新，不能再用 `scopeLimits` 含糊保留已完成项。
