界面插画的送达方式：宿主半区注册 `GET /doraemon-paper-reader/assets/*`（`src/index.js`），

原版 PDF 保留为核对保险，不随插件发布样本论文。

## PDF 入口（当前可用）

1. 打开「论文阅读器」→「PDF 文件」；
2. 点击选择或拖入一个 PDF（只接受 PDF，≤ 200 MB）；
3. 点「大肥鱼给朕速速抄写！！！」；
4. 加载页显示阶段与计时；关掉页签后任务仍在 DSH 进程内继续（DSH 关闭则任务状态丢失）；
5. 完成后点「打开阅读页」，在 `doraemon-paper-reader-doc` 页签里读 MirrorDoc 版 HTML；
6. 图/表/公式是原页裁剪，正文带页码/位置戳；原版页可点开核对。

PDF 管线默认使用受管环境 `$DSH_HOME/doraemon-paper-reader/python-env/`。首次任务会从基础 Python 创建 venv，并安装 `pdfplumber` / `pypdfium2` / `Pillow` / `matplotlib`；最后一项只用于 KaTeX 失败后的公式 SVG 回退。也可执行 `npm run setup:python` 预装。所有 pip cache 与临时文件都落在 D 盘。

## 论文库与持久化

- 主界面下方有「最近论文」列表：标题、作者、DOI、批注数；点击直接打开该论文的阅读页；
- 作业目录本身就是论文库：`$DSH_HOME/doraemon-paper-reader/jobs/<jobId>/` 里的 `paper-summary.json` 提供元数据，`annotations.json` 保存这篇论文的批注；
- 批注新增/修改/发送/删除后，浏览器端防抖写回 `annotations.json`；刷新页面或重启 DSH 后，阅读页会从磁盘恢复段尾气泡与历史批注；
- `mirrordoc.json`、`assets/`、`source-pages/` 在没有内存任务时也会从磁盘读取；已完成作业的状态路由同样从磁盘恢复为 `done/done`（不伪造运行进度），所以重启后「最近论文」和旧 `lastJobId` 都不再 404；
- PDF 已有 DOI/元数据会直接展示；标题/作者/刊物/年份查询见下一节。

## 信息查询（B）

- 输入不要求填满：标题、DOI、arXiv、作者、刊物/会议、年份、自由关键词可以任填一个或多个；
- 先询问“严格要正式版”还是“可用预印本/OA 版”：
  - 严格正式版：只查元数据并给 `doi.org` / 官方页面链接，不擅自用预印本替代；已有本地副本会另外给出“打开已有本地副本”；
  - 可用预印本/OA：按 `arXiv HTML → arXiv PDF → 合法 OA PDF → metadata-only` 取回；
- 标题/多字段查询先给候选列表，候选可显示 OA 标记与已有本地副本；
- 来源记录 `route / license / version / fetchedAt / sha256`，阅读页显示来源与版本徽标；
- 没有合法全文时只给元数据卡和官方链接，不抓付费墙、不绕过 403/验证码。

## 阅读页选区与批注

- 选中正文或摘要会出现「问大肥鱼」+ 默认空白的问题框（只给 placeholder）；点它把批注加入主对话输入区上方的批注条；
- 「问大肥鱼」浮层使用文档坐标的恒定 8px 偏移逐帧跟随；顶部以阅读页工具栏的实际下沿（含横线）为界，到达上/下边界才夹住，选区回到视口内立即恢复原偏移（无过渡延迟）；
- 批注条只负责收集/编辑批注；**不再有「整体问题」文本框，也没有独立的「发送批注」按钮**。用户在主输入框写问题，按回车或点主发送键，批注会随这条消息一起发送；
- 支持跨多段选区与多次选区累积；图表/公式右键直接弹出批注框；图表与文本一起框选会作为同一批注的多段；
- 特殊块（Table / Figure / Equation）右键后可正常点进批注框打字；批次里会带上 `label`（如 `Table 1`）、`asset`、只读 `assetPath` 与原块文本，摘要也优先显示 `Table 1` / `Figure 1` / `Equation 1`；模型需要看图时可自行对 `assetPath` 调用 `read_image`，不会无条件把大图塞进每次请求；
- 上下文包含标题、DOI/arXiv、版本戳、页码、原文、前后文、同页图表/公式，以及 `paper-summary.json`（也在 `MirrorDoc.meta.brief`）；
- 按回车或点主发送键时，完整批注包先存到 `$DSH_HOME/doraemon-paper-reader/annotation-batches/<batchId>.json`；用户消息只显示「📝 N 条批注」、每条批注的页码/章节和问题摘要，以及一个短批次号；模型通过 `doraemon_read_annotations` 按批次号取回完整原文与上下文，再作答；
- 发送后原文段尾出现可删除的数字气泡；摘要与正文共用同一套持久化和气泡；点气泡滚回原段，并播放两次亮/浅记号笔过渡后落到浅色高亮。
- 模型回答里的原段回跳使用 `citationUrl`：聊天消息里直接给出 `[p.N](http://…/api/open?…)`；点击后回跳页通过 BroadcastChannel 通知宿主，打开对应论文块并高亮。即使模型忘了生成链接，用户消息里的回跳链接也可直接使用。

## 引用蓝链与引用预览

- 正文 `[1]` / `[1,2]` / `[1–3]` 会变成蓝链；引用索引由宿主从 MirrorDoc 生成，前端不重复跑引用正则；
- 点击蓝链弹出引用预览卡：左侧目录（文章概览 / 引用关系 / 依据与来源），右侧可滚动内容；点目录会带动右侧滚到对应段，右侧滚动也会反更目录高亮；
- 预览优先复用论文库，其次查合法 OA/arXiv；没有合法全文时只做摘要/元数据概览，并明确标注“未核对全文”，不伪造全文结论；
- 概览固定为研究背景/研究问题/方法/结论/关键证据/局限六项，要求比简要版详细约 2–3 倍；引用关系固定为 stance + 2–4 条要点，每条分别给“引用处”和“被引论文”的依据；
- 分析结果落 `citation-cards/` 持久缓存；同一引用下次打开直接复用，不再查源或调模型；引用蓝链用宿主 link token 混出的浅蓝色，和正文区分；
- 「精读这篇」进入信息查询页，按 reference/metadata 预填标题、作者、年份、DOI/arXiv，保留正式版/OA 选择，并提供「返回引用处」；预览任务完成时可在查询页直接打开预览副本（提升为正式作业，未完成预览不会污染「最近论文」）。

## 语言切换与对照阅读

- 阅读页右上角的三态按钮：`原文 → 中文 → 对照 → 原文`；模式按论文 job 记住；
- 中文模式与对照模式复用同一份引用索引：英文 `[n]` 和中文 `[n]` 都会打开同一个引用预览，不做第二套存储；
- 翻译按 1–3 句、约 360 字符切成语义小段，中文模式按块回填，对照模式按英文小段 / 中文小段交替显示，不把整段英文和整段中文硬拼在一起；
- 段内小段间距 8px，段落间 16px；目标译文左侧用 link 色竖线标记；公式、图片、表格原样保留，其中公式只显示原图与编号，代码与参考文献不翻译；
- 译文落 `translations.zh.json`，按原文 hash + 语言 + 模型 + promptVersion 缓存；后台任务可断点续跑，失败段回退原文并显示提示。
- 阅读页「术语」按钮可查看自动候选、填写中文译名、锁定专名并保存；术语 hash 进入缓存键，改术语会触发对应重译；
- 每次翻译生成 `qa`：空译、未翻译、无中文、引用/数字/数词、术语一致性都会成为告警；阅读页显示“译文质量告警 N 条”，不会让空译静默通过。
- 阅读页「公式」按钮会逐张把方程裁剪图转成 LaTeX，校验括号/置信度后提供「复制 LaTeX」；「表格」按钮把表格整理为行列并翻译单元格，所有数字必须能在 PDF 文本层找到，否则保留原图并告警。
- 「复核」按钮先做逐段英文回译，再比较原文/当前译文/回译，检查漏译、增译、数字、引用、因果/情态、术语；通过校验的修订自动写回，未修复问题再做一轮定向 repair，仍无法安全修复的保留现译。复核日志只用于追溯，不要求用户逐条确认。
- 公式低置信度/括号不平衡时自动重试并优先保留原图；手动修正仅作为高级兜底。阅读页版本徽标可手动确认 VOR/录用稿/预印本，但不阻塞阅读。

旋转表格（整页 glyph 方向旋转 90/270°）不再逐字当正文读取：提取器会保存整页表格裁剪、顺时针转正后作为 Table 图片块，并跳过其文字行；`layoutAudit` 会记录 `rotatedTablePages`。首页全宽摘要下的双栏、期刊 editor/date/copyright/funding 元数据块、未标 Abstract 的摘要也会单独处理；MDPI 首页左栏元数据只清理本栏，不吞右栏摘要/正文；全宽参考文献页不会因词首分布在页面中部而被误判双栏；“页顶双栏 + 底部全宽大图”会在全宽图前停止列桶，避免图注与正文碎片交错；CMSY 英寸符号、公式限定行与大写图注续行会确定性并回原块。

PDF 管线在第一次提取后会自动跑 `reconcile_layout.py` 做二次格式复核：首行缩进/正常行距切段、跨栏与跨页续段合并、run-in 标题回收、文本空白规范化、表格 caption 前导点清理、表线/表体识别、重复 caption 与 DOI 噪声清理、Supporting Information/Data S1 分块、表格裁剪图与原始页 bbox/像素差异审计；双栏页面会按词首推断栏缝，并按“左栏 → 右栏 → 底部全宽表”重排；随后做**逻辑章节归一化**：Supporting Information → REFERENCES 1..N → ACKNOWLEDGMENTS / Author Contributions，`layoutAudit.orderMap` 记录最终章节序列，参考文献编号缺失或重复会进 warnings。每个表会生成 `audit/layout-audit.png` 的“原页 vs 阅读器裁剪”并排图。

第三级顺序审计是可选的：`python 工具/pdf-pipeline/ai_order_audit.py <job目录>` 会把全文压成章节层级 + 每节开头 + 参考文献范围的紧凑摘要（约 4–5 KB），让模型只输出 `ok/issues`，不改写正文；`--outline-only` 不联网，只生成 `audit/ai-order-input.txt`。

聊天回答里的引用链接已接入阅读页：模型回答给出 `citationUrl`，点击后通过 `.dprcite` 导航桩与 BroadcastChannel 打开对应论文块并高亮；真实模型回答 → 回跳的 L2 已通过（D-049）。

## 多篇对照、版本与产物

- **多篇综述**：选 2–3 篇进入全宽工作台；左侧两篇全文按 8:3 与右侧工作台分栏，两篇都保留单篇阅读的选区批注、引用蓝链、原文/中文/对照、术语、逐字高亮、KaTeX 和表格网格。
- **引用双篇**：从 `[n]` 蓝链或阅读页「双篇对照」进入，固定 A=引用方、B=被引论文；支持度分四档，没有有效证据时明确降级为「证据不足」。
- **版本差异**：同一 DOI/标题的两个本地镜像可标成 VOR、录用稿、预印本；「版本对照」显示两侧版本徽标，「版本差异」按段落级 LCS 确定性输出新增/删除/改写候选。
- **有出处数据图**：柱状图/折线图只能使用对照表或论文档案里已经出现的数字；每个点必须带 `jobId`、`blockId`、`quote`，核不过的点直接丢弃。
- **概念图**：模型可以组织问题、方法、证据、结果、局限、缺口和研究机会；论文事实节点必须带原文锚点，跨论文归纳用虚线显示并标「模型归纳」，无出处数字节点会被丢弃。
- **产物浮窗**：表格、论证链、概念图、结构统计、证据覆盖、数据图、汇总可同时开多个浮窗；支持拖动、缩放、Esc 关闭、Markdown 复制/下载和本地归档。归档目录为 `$DSH_HOME/doraemon-paper-reader/compare-archives/`。

## 论文术语即时查词

- 单篇阅读页和双篇论文栏选中单词、缩写或短语后，点「查词」；
- 宿主重新读取当前段落，先查已保存术语表和论文内 `Full Name (ABC)` / `ABC Full Name` 定义；缺少可靠中文解释时才调用模型；
- 临时查词卡显示本文语境义、论文内全称、同一缩写有多个候选时的全部候选、简短模型补充、当前句、页码/章节/blockId，可定位原段；
- 查词不新增批注、不发送到主对话；查询缓存只在宿主内存中，重启清空；
- 不提供收藏、生词本、标签、掌握度、SRS 或发音，因为该功能定位是论文即时理解，不是英语学习。

## 开发回路

```powershell
# 1) 装进开发 profile（链接方式，改完无需发布）
dsh plugin --profile dev add link:D:\DSH-Plugins\dsh-doraemon-paper-reader

# 2) 跑 L0 单元测试（不需要 Harness）
npm test

# 2.1) 三篇异形论文的真实 PDF 回归（Sensors / Plague / PLOS）
npm run test:pdf-regression

# 3) 起开发 profile 观察加载日志
dsh dev
```

改动宿主半区（`src/*.js`）后重启 profile 生效。浏览器半区（`src/client.js`）是单文件、无构建，
改完重启 profile 或刷新页面都会重新取到新文件（`dsh` 按文件 mtime/size 生成新的 rev，不靠缓存）。
开发期用独立端口起实例，别占日常 `web` 的 3080：

```powershell
$env:DSH_HOME='D:\DSH\home'; dsh --profile dev --no-open --port 3105
```

## 硬约定

1. **自包含，而不是口号式零依赖**：不把第三方插件写进 dependencies/peerDependencies、不 import 其运行时、不 monkey-patch 官方服务；
   但允许随包 vendoring 高价值静态资产（当前为 KaTeX JS/CSS/font），条件是许可登记、失败降级与 GitHub/安装包可一次装好。详见 `AGENTS.md` §2.2。
2. **命名自占**：slot key、页签 kind、路由前缀、locale 命名空间、配置命名空间、数据目录全部带本包前缀。
3. **保真 > 速度**：镜像构建必须有覆盖率台账，不允许静默丢内容。
4. 付费墙内容只做深度链接与元数据，不抓正文。
